AI Data Analyst

An AI-powered data analysis application built with Python, Streamlit, Scikit-learn, and Google Gemini.

Features

* CSV Upload: Upload datasets for analysis.
* Data Cleaning: Automatically handle missing values and duplicate records.
* Exploratory Data Analysis: View dataset statistics, column types, and correlations.
* AI Insights: Generate natural-language insights about datasets using Google Gemini.
* Regression: Predict numerical outcomes using Linear Regression, with R² and MAE evaluation.
* Classification: Compare Logistic Regression, Decision Tree, and Random Forest classifiers, with hyperparameter tuning using GridSearchCV.
* Clustering: Discover groups using K-Means, with feature scaling, cluster profiles, and silhouette scores.
* AI Model Interpretation: Generate explanations of regression, classification, and clustering results.

Technologies Used

* Python
* Streamlit
* Pandas
* Scikit-learn
* Google Gemini API

How to Run

1. Clone the repository.
2. Install dependencies using pip install -r requirements.txt.
3. Configure your Google Gemini API key in Streamlit secrets.
4. Run the application using streamlit run ai-data-analyst.py

Project Purpose

This project demonstrates the integration of data preprocessing, machine learning, model evaluation, and generative AI to make data analysis more accessible and interpretable.
